## 异常类型
| 异常                   | 什么时候抛        | 例子                    | 通常怎么处理        |

### 模式:
r    读，文件不存在会报错
w   写，会清空原文件
a    追加，写到末尾，写的语法和w一样
r+  读写

读
with open("data.txt", "r", encoding="utf-8") as f:
    for line in f:
        print(line.strip())
        
==f.read()==             # 整个文件成一个**字符串**
==f.readlines()==     # 每行一个元素，列表（注意每行结尾会有\n）
==for line in f:==   # 逐行，最省内存

写
with open("out.txt", "w", encoding="utf-8") as f:
    f.write("hello\n")
    f.writelines(["a\n", "b\n"])
    
write() 不会自动换行，\n 要自己写。而且 "w" 会清空原文件
"w"和"a"模式下，指定的文件不存在时会创建，"r+"不行
