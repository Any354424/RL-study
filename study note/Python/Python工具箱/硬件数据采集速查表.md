# 串口（pyserial）

> `import serial`。串口收到的是 **`bytes`**，必须先 `.decode()` 才能当字符串处理。

## 函数

| 函数 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `serial.Serial(port, baudrate, ?timeout=1)` | 打开串口；`8N1` 是默认值 | `Serial` 对象 | `serial.Serial('COM3', 115200, timeout=1)` |
| `serial.tools.list_ports.comports()` | 列出系统所有串口 | `list` | `[p.device for p in comports()]` → `['COM3','COM5']` |

> `serial.Serial` 的常用参数：`bytesize`（默认 8）、`parity`（默认 N）、`stopbits`（默认 1）、`timeout`（读超时，秒）、`write_timeout`。

## Serial 对象

| 方法/属性 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `ser.readline()` | 读到 `\n` 或超时；**返回值含 `\n`** | `bytes` | `b'1.0,2.0\n'` |
| `ser.read(n)` | 读 n 个字节，不够就等到超时 | `bytes` | `ser.read(10)` |
| `ser.read_all()` | 读缓冲区里现有的全部 | `bytes` | `ser.read_all()` |
| `ser.write(数据)` | 写字节；参数必须是 `bytes` | `int`（写入字节数） | `ser.write(b'START\n')` |
| `ser.in_waiting` | 输入缓冲区里还有多少字节 | `int` | 持续增长说明处理不过来 |
| `ser.is_open` | 串口是否已打开 | `bool` | `if not ser.is_open:` |
| `ser.reset_input_buffer()` | 清空输入缓冲区 | `None` | 打开后先清一次 |
| `ser.reset_output_buffer()` | 清空输出缓冲区 | `None` | |
| `ser.flush()` | 等待数据真正发完 | `None` | |
| `ser.close()` | 关闭串口 | `None` | 不关 → 下次报“端口被占用” |
| `ser.port` / `ser.baudrate` | 当前端口 / 波特率 | `str` / `int` | |

## 异常

| 异常 | 触发场景 |
|---|---|
| `serial.SerialException` | 端口不存在、被占用、设备断开 |
| `serial.SerialTimeoutException` | 写超时 |

## 坑

| 坑 | 说明 |
|---|---|
| 包名 ≠ 导入名 | `pip install pyserial`，代码里 `import serial` |
| `timeout=None` | 读操作**永久阻塞**，没数据就卡死；一定给个秒数 |
| 端口名会变 | 换个 USB 口，`COM3` 可能变 `COM5`；用 `comports()` 动态找 |
| 忘记 `close()` | 端口被占用，下次打不开；用 `with` 或 `finally` |
| 混用 `read` 和 `readline` | 两者共享缓冲区，容易读到半截数据 |

# 字节与字符串

> `bytes` 是原始字节，`str` 是文本。串口、文件（二进制模式）、网络都给你 `bytes`。

## 方法

| 方法 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `raw.decode(?编码='utf-8', ?errors='strict')` | 字节 → 字符串 | `str` | `b'1.0\n'.decode() = '1.0\n'` |
| `s.encode(?编码='utf-8')` | 字符串 → 字节 | `bytes` | `'1.0'.encode() = b'1.0'` |
| `raw.hex()` | 转成十六进制字符串，调试用 | `str` | `b'\x01\x02'.hex() = '0102'` |
| `b.strip()` / `b.rstrip()` | 去两端 / 右侧空白字节 | `bytes` | `b'1.0\n'.strip() = b'1.0'` |
| `b.split(分隔符)` | 按字节切分 | `list` | `b'a,b'.split(b',') = [b'a', b'b']` |

## 坑

| 坑 | 说明 |
|---|---|
| `errors="ignore"` | 半包时可能有不完整字节，加它避免 `UnicodeDecodeError` 崩程序 |
| `b"1" + "2"` | `bytes + str` 直接 `TypeError`，必须统一类型 |
| `strip()` 去的是**字符集合** | 不是子串；`strip('ab')` 会去掉首尾所有 `a` 和 `b` |

# 时间

> `import time`。**存 CSV 用 `time.time()`，算间隔用 `perf_counter()`。**

## 函数

| 函数 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `time.time()` | Unix 时间戳（秒），可存盘 | `float` | `1794041389.455` |
| `time.perf_counter()` | 高精度计时器，适合算耗时 | `float` | `t0 = perf_counter()` |
| `time.monotonic()` | 单调时钟，不受系统对时影响 | `float` | 算时间差更稳 |
| `time.sleep(秒)` | 暂停 | `None` | `time.sleep(0.01)` |
| `time.strftime(格式, ?时间元组)` | 时间 → 字符串 | `str` | `time.strftime('%Y-%m-%d')` |

## 坑

| 坑 | 说明 |
|---|---|
| 用 `time.time()` 算间隔 | 系统对时会让它跳变，差值可能是负数；用 `perf_counter()` |
| `time.time()` 精度 | 毫秒级；做高精度对齐要靠设备端时间戳 |

# 路径（pathlib / os）

> `from pathlib import Path`。**新代码优先用 `pathlib`**，`os` 只用于 `getcwd` 和环境变量。

## 函数

| 函数 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `Path(路径)` | 创建路径对象（不检查存在、不创建） | `Path` | `Path('data')` |
| `Path(a) / b` | 拼接路径 | `Path` | `Path('data') / 'a.csv'` |
| `os.getcwd()` | 当前工作目录 | `str` | `F:\桌面\proj` |
| `os.listdir(?路径)` | 目录内容 | `list` | `os.listdir('.')` |

## Path 对象

| 方法/属性 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `p.exists()` | 是否存在 | `bool` | `p.exists()` |
| `p.mkdir(?parents=False, ?exist_ok=False)` | 建目录 | `None` | `p.mkdir(exist_ok=True)` |
| `p.read_text(?encoding)` | 一次读完 | `str` | `p.read_text(encoding='utf-8')` |
| `p.write_text(内容, ?encoding)` | 一次写完 | `int` | `p.write_text('hi')` |
| `p.glob(模式)` | 按模式找文件 | 生成器 | `p.glob('*.csv')` |
| `p.name` / `p.stem` / `p.suffix` | 文件名 / 去后缀 / 后缀 | `str` | `'a.csv'` / `'a'` / `'.csv'` |
| `p.parent` | 父目录 | `Path` | `Path('data')` |

## 坑

| 坑 | 说明 |
|---|---|
| `Path('data')` 不等于建目录 | 它只是地址；要 `mkdir()` |
| 相对路径的基准 | 是**当前工作目录**，不是脚本所在目录；用 `os.getcwd()` 确认 |
| 中文路径 | 纯 Python 没事，但编译 C 扩展、CMake 时可能出问题 |

# CSV

> `import csv`。**读写都要加 `newline=""`**，否则 Windows 上多空行。

## 函数

| 函数 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `csv.writer(f, ?delimiter=',')` | 创建写入器 | `writer` 对象 | `csv.writer(f)` |
| `csv.reader(f)` | 创建读取器（逐行迭代） | 迭代器 | `for row in csv.reader(f)` |
| `csv.DictReader(f)` | 按表头把每行转成字典 | 迭代器 | `row['ax']` |
| `csv.DictWriter(f, fieldnames=列名列表)` | 创建字典写入器 | `DictWriter` 对象 | `DictWriter(f, fieldnames=['a','b'])` |

## 对象方法

| 方法 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `w.writerow(列表)` | 写一行；参数**必须是列表** | `int` | `w.writerow(['a', 1])` |
| `w.writerows(二维列表)` | 一次写多行 | `None` | `w.writerows(rows)` |
| `dw.writeheader()` | 按 `fieldnames` 写表头 | `int` | `dw.writeheader()` |
| `dw.writerow(字典)` | 按列名写一行字典 | `int` | `dw.writerow({'a':1})` |
| `next(reader)` | 取下一行（常用来跳表头） | `list` | `next(r)` |

## 坑

| 坑 | 说明 |
|---|---|
| `w.writerow("a,b,c")` | 字符串被当成字符序列，**一个字符一列**；要传 `["a","b","c"]` |
| 读出来全是字符串 | `'90'` 不是 `90`，用之前自己 `float()` |
| 少写 `newline=""` | 每行之间多一个空行 |
| Excel 打开中文乱码 | 写文件用 `encoding='utf-8-sig'` |

# 命令行参数（argparse）

> `import argparse`。让脚本接受 `--port COM3 --baud 115200` 这种参数。

## 函数

| 函数 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `argparse.ArgumentParser(?description=说明)` | 创建解析器 | `ArgumentParser` | `ArgumentParser(description='采集')` |
| `parser.add_argument(名字, ?type=, ?default=, ?help=)` | 声明一个参数 | `Action` | `add_argument('--top', type=int, default=3)` |
| `parser.parse_args(?参数列表)` | 解析命令行 | `Namespace` | `args = parser.parse_args()` |

## 规则

| 写法 | 类型 | 命令行 | 取值 |
|---|---|---|---|
| `add_argument("file")` | 位置参数 | `data.txt` | `args.file` |
| `add_argument("--top")` | 可选参数 | `--top 5` | `args.top` |
| `add_argument("--verbose", action="store_true")` | 开关 | `--verbose` | `args.verbose`（`True`/`False`） |

## 坑

| 坑 | 说明 |
|---|---|
| 位置参数带 `--` | 会报 `unrecognized arguments`；代码里没写 `--`，命令行就别写 |
| 参数名里的 `-` | `--max-len` 存进去是 `args.max_len` |
| `parse_args()` 出错 | 抛 `SystemExit`，不是 `ValueError`，`except ValueError` 接不住 |

# JSON

> `import json`。存配置、校准参数、实验记录。

## 函数

| 函数 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `json.load(f)` | 从文件读成 Python 对象 | `dict`/`list` | `cfg = json.load(f)` |
| `json.dump(obj, f, ?ensure_ascii=True, ?indent=)` | 写进文件 | `None` | `json.dump(cfg, f, ensure_ascii=False, indent=2)` |
| `json.loads(s)` | 从字符串解析 | 对象 | `json.loads('{"a":1}')` |
| `json.dumps(obj)` | 转成字符串 | `str` | `json.dumps({'a':1})` |

## 坑

| 坑 | 说明 |
|---|---|
| 中文变成 `\uXXXX` | 加 `ensure_ascii=False` |
| 文件不好读 | 加 `indent=2` |
| 格式坏了 | 抛 `json.JSONDecodeError`（`ValueError` 的子类） |

# 采集骨架

```python
import serial, csv, time, argparse

def main(port, baud, out):
    try:
        ser = serial.Serial(port, baud, timeout=1)
    except serial.SerialException as e:
        print(f"打开失败: {e}")
        return

    ser.reset_input_buffer()
    bad = 0
    with open(out, "w", newline="", encoding="utf-8") as f:
        w = csv.writer(f)
        w.writerow(["ts", "ax", "ay", "az", "gx", "gy", "gz"])
        try:
            while True:
                raw = ser.readline()
                if not raw:
                    continue
                line = raw.decode("utf-8", errors="ignore").strip()
                parts = line.split(",")
                if len(parts) != 7:
                    bad += 1
                    continue
                try:
                    row = [float(x) for x in parts]
                except ValueError:
                    bad += 1
                    continue
                w.writerow([f"{time.time():.3f}"] + row)
        except KeyboardInterrupt:
            print(f"\n停止，坏行 {bad}")
        finally:
            ser.close()

if __name__ == "__main__":
    p = argparse.ArgumentParser()
    p.add_argument("port")
    p.add_argument("--baud", type=int, default=115200)
    p.add_argument("--out", default="data.csv")
    a = p.parse_args()
    main(a.port, a.baud, a.out)
```

# 附：常用换算

| 换算 | 公式 |
|---|---|
| 波特率 → 字节/秒 | `波特率 / 10`（8N1 时每字节 10 位） |
| 115200 → | 约 11520 字节/秒 |
| 921600 → | 约 92160 字节/秒 |
| 加速度 g → m/s² | `g * 9.81` |
| 角速度 °/s → rad/s | `°/s * π / 180` |
| 采样率 Hz → 周期 | `1000 / Hz` 毫秒 |
