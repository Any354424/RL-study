> **注**
>
> - 函数 = `function(参数)`；方法 = `对象.method(参数)`
> - **`?` 表示可选参数**，默认值见「作用」列；没有 `?` 的是必填
> - `-->` 表示原对象被修改后的状态；`=` 表示表达式的返回值
> - 部分参数只能按位置传，具体以方法为准：`s.find('k', start=0)` 会 `TypeError`
> - 标准签名以 [Python 标准库文档](https://docs.python.org/zh-cn/3/library/index.html) 为准

# 数学
> `ceil`/`floor`/`exp`/`fabs`/`log`/`log10`/`modf`/`pow`/`sqrt` 等属于 `math` 模块，需 `import math`；`abs`/`max`/`min`/`round`/`pow` 是内置函数，不用导入。`random.` 开头的需 `import random`。

## 内置与 math 函数

| 函数                     |                      作用                       | 返回      | 示例                                                    |
| ---------------------- | :-------------------------------------------: | ------- | ----------------------------------------------------- |
| `abs(x)`               |                      绝对值                      | 数值      | `abs(-10) = 10`                                       |
| `math.ceil(x)`         |                上取整（向上取到最近的整数）                 | `int`   | `math.ceil(4.1) = 5`                                  |
| `math.floor(x)`        |                      下取整                      | `int`   | `math.floor(4.9) = 4`                                 |
| `math.exp(x)`          |                   e 的 x 次幂                    | `float` | `math.exp(1) = 2.718281828459045`                     |
| `math.fabs(x)`         |                  以浮点数形式返回绝对值                  | `float` | `math.fabs(-10) = 10.0`                               |
| `math.log(x, ?base=e)` |            x 的对数；不传 base 默认以 e 为底             | `float` | `math.log(math.e) = 1.0`<br>`math.log(100,10) = 2.0`  |
| `math.log10(x)`        |                  以 10 为底的对数                   | `float` | `math.log10(100) = 2.0`                               |
| `max(x1, x2, ...)`     |             最大值；参数可以是多个值，也可以是单个序列             | 元素本身    | `max(1,3,2) = 3`<br>`max([1,3,2]) = 3`                |

| `math.modf(x)`         |        拆成（小数部分, 整数部分），符号与 x 相同，整数部分为浮点        | `tuple` | `math.modf(3.5) = (0.5, 3.0)`<br>注意先小数后整数             |
| `pow(x, y)`            |              x 的 y 次幂，等价 `x**y`               | 数值      | `pow(2,3) = 8`                                        |
| `round(x, ?n)`         | 就近舍入，恰好居中时取偶数；对浮点数，省略位数返回整数，指定位数则返回浮点数 | 数值      | `round(3.14159, 2) = 3.14`<br>`round(2.5) = 2`（舍入到偶数） |
| `math.sqrt(x)`         |                      平方根                      | `float` | `math.sqrt(16) = 4.0`                                 |

# 字符串 `'abc'`

## 函数

| 函数 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `len(对象)` | 元素个数 | `int` | `len('abc') = 3` |
| `max(可迭代对象)` | 最大的字符（按 Unicode 码点） | `str` | `max('abc') = 'c'` |
| `min(可迭代对象)` | 最小的字符 | `str` | `min('abc') = 'a'` |
| `str(对象)` | 把任意对象转成字符串 | `str` | `str(90) = '90'` |

## 方法
> 字符串**不可变**：所有方法都不改原串，而是返回新值。

| 方法                             |           作用            | 返回     |                            示例                             |
| ------------------------------ | :---------------------: | ------ | :-------------------------------------------------------: |
| `s.center(总宽度)`                |      居中，两侧补空格到总宽度       | `str`  |                `'ab'.center(6) = '  ab  '`                |
| `s.count(子串, ?起点, ?终点)`        | 统计子串出现次数；起点默认 0，终点默认到末尾 | `int`  | `'ababa'.count('a') = 3`<br>`'ababa'.count('a',1,3) = 1`  |
| `s.endswith(后缀, ?起点, ?终点)`     |        是否以某后缀结尾         | `bool` |            `'abc.txt'.endswith('.txt') = True`            |
| `s.find(子串, ?起点, ?终点)`         |   第一次出现的下标；找不到返回 `-1`   | `int`  |    `'abcabc'.find('bc') = 1`<br>`'abc'.find('x') = -1`    |
| `s.index(子串, ?起点, ?终点)`        |     同 `find`，但找不到报错     | `int`  |     `'abcabc'.index('bc') = 1`<br>找不到 → `ValueError`      |
| `s.isalnum()`                  |     至少一个字符，且全是字母或数字     | `bool` |                 `'ab12'.isalnum() = True`                 |
| `s.isalpha()`                  |      至少一个字符，且全是字母       | `bool` |                 `'abc'.isalpha() = True`                  |
| `s.isdigit()`                  |     至少一个字符，且全是数字字符      | `bool` |  `'123'.isdigit() = True`<br>`'12.5'.isdigit() = False`   |
| `s.join(可迭代序列)`                |   用 `s` 作分隔符，把序列连成字符串   | `str`  |            `'-'.join(['a','b','c']) = 'a-b-c'`            |
| `s.lower()`                    |          全部转小写          | `str`  |                  `'AbC'.lower() = 'abc'`                  |
| `s.lstrip(?要删的字符)`             |    去掉**左边**的字符；默认删空白    | `str`  |               `'  ab  '.lstrip() = 'ab  '`                |
| `s.replace(旧内容, 新内容, ?最多替换几次)` |    替换子串；默认 `-1` 表示全部    | `str`  |           `'abab'.replace('a','x',1) = 'xbab'`            |
| `s.rfind(子串, ?起点, ?终点)`        |  最后一次出现的下标；找不到返回 `-1`   | `int`  |                `'abcabc'.rfind('bc') = 4`                 |
| `s.rsplit(?分隔符, ?最多切几次)`       |       从**右边**开始切分       | `list` |           `'a-b-c'.rsplit('-',1) = ['a-b','c']`           |
| `s.rstrip(?要删的字符)`             |    去掉**右边**的字符；默认删空白    | `str`  |               `'  ab  '.rstrip() = '  ab'`                |
| `s.split(?分隔符, ?最多切几次)`        |   按分隔符切分；不写分隔符按任意空白切    | `list` |           `'a-b-c'.split('-') = ['a','b','c']`            |
| `s.startswith(前缀, ?起点, ?终点)`   |        是否以某前缀开头         | `bool` |           `'abc.txt'.startswith('abc') = True`            |
| `s.strip(?要删的字符)`              |    去掉**两端**的字符；默认删空白    | `str`  | `'  ab  '.strip() = 'ab'`<br>`'xxabxx'.strip('x') = 'ab'` |
| `s.upper()`                    |          全部转大写          | `str`  |                  `'AbC'.upper() = 'ABC'`                  |

### 三个高频坑

| 坑 | 说明 |
|---|---|
| `split()` 和 `split(" ")` | 前者按**任意空白**切，合并连续空白、丢弃空串；后者严格按单个空格切，保留空串 |
| `strip("ab")` | 参数是**字符集合**不是子串，`'abab'.strip('ab') = ''` |
| `split("")` | 直接 `ValueError: empty separator`，**不能用空字符串当分隔符** |

# 列表 `[a,b,c]`

## 函数

| 函数 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `len(对象)` | 元素个数 | `int` | `len([1,2,3]) = 3` |
| `max(可迭代对象)` | 最大元素 | 元素本身 | `max([1,3,2]) = 3` |
| `min(可迭代对象)` | 最小元素 | 元素本身 | `min([1,3,2]) = 1` |
| `list(?可迭代对象)` | 转成列表；不传参数返回 `[]` | `list` | `list('abc') = ['a','b','c']` |
| `sorted(可迭代对象, *, ?key=比较依据, ?reverse=是否降序)` | 排序并返回**新列表**，原对象不动 | `list` | `sorted([3,1,2]) = [1,2,3]` |

> `*` 表示 `key` / `reverse` **只能按关键字传**：`sorted(x, len)` 会 `TypeError`，必须写 `key=len`。
## 方法

| 方法                                   | 作用                                   | 返回          | 示例                                                                  |
| ------------------------------------ | ------------------------------------ | ----------- | ------------------------------------------------------------------- |
| `lst.append(元素)`                     | 末尾追加**一个**对象                         | `None`      | `['a','b'].append('c') --> ['a','b','c']`                           |
| `lst.insert(下标, 元素)`                 | 在下标**之前**插入                          | `None`      | `[0,1,2].insert(1,'a') --> [0,'a',1,2]`                             |
| `lst.extend(可迭代序列)`                  | 把另一个序列的元素**逐个**加入                    | `None`      | `['a','b'].extend(['c','d']) --> ['a','b','c','d']`                 |
| `lst.remove(要删的值)`                   | 删除第一个等于该值的元素                         | `None`      | `['a','a','b'].remove('a') --> ['a','b']`<br>不存在 → `ValueError`     |
| `lst.pop(?下标)`                       | 删除指定下标的元素并返回它；下标默认 `-1`              | 被删元素        | `x.pop() = 'c'`，同时 `x --> ['a','b']`                                |
| `lst.clear()`                        | 清空列表                                 | `None`      | `x.clear() --> []`                                                  |
| `del lst[下标]`                        | 删除指定下标的元素（**语句**，不是方法）               | 无           | `del x[1] --> ['a','c']`                                            |
| `lst.count(要数的值)`                    | 该值出现的次数                              | `int`       | `['k','s','k'].count('k') = 2`                                      |
| `lst.index(要找的值, ?起点, ?终点)`          | 第一次出现的下标                             | `int`       | `['k','s','k'].index('k') = 0`<br>不存在 → `ValueError`                |
| `lst.sort(?key=比较依据, ?reverse=是否降序)` | 原地排序                                 | `None`      | `['a','ab','abc'].sort(key=len, reverse=True) --> ['abc','ab','a']` |
| `lst.reverse()`                      | 原地反转                                 | `None`      | `[3,2,5].reverse() --> [5,2,3]`                                     |
| `lst.copy()`                         | 浅拷贝                                  | `list`（新列表） | `['a','b'].copy() = ['a','b']`                                      |

## 坑

| 坑                    | 说明                                                                        |
| -------------------- | ------------------------------------------------------------------------- |
| `append` vs `extend` | `append([1,2])` 整体塞进去 → `[..., [1,2]]`；`extend([1,2])` 拆开 → `[..., 1, 2]` |
| `x = x.sort()`       | `sort` 返回 `None`，这么写会把 `x` 变成 `None`                                      |
| `b = a`              | 不是拷贝，是同一个对象的两个名字；要拷贝用 `a.copy()` 或 `a[:]`                                 |

# 元组 `(a,b,c)`

> 元组不可变，只有下面两个方法；列表的增删改方法一个都没有。
## 函数

| 函数              | 作用                     | 返回      | 示例                                                           |
| --------------- | ---------------------- | ------- | ------------------------------------------------------------ |
| `len(元组)`       | 元素个数                   | `int`   | `len((1,2,3)) = 3`                                           |
| `max(可迭代对象)`    | 最大元素                   | 元素本身    | `max((1,3,2)) = 3`                                           |
| `min(可迭代对象)`    | 最小元素                   | 元素本身    | `min((1,3,2)) = 1`                                           |
| `tuple(?可迭代对象)` | 把可迭代对象转成元组；不传参数返回 `()` | `tuple` | `tuple([1,2,3]) = (1,2,3)`<br>`tuple('abc') = ('a','b','c')` |

## 方法

| 方法 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `t.count(要数的值)` | 该值出现的次数 | `int` | `(1,2,1).count(1) = 2` |
| `t.index(要找的值, ?起点, ?终点)` | 第一次出现的下标 | `int` | `('a','b').index('b') = 1` |

> 这两个和 `list.count` / `list.index` 的参数、返回值完全一致，查列表那节即可。

# 字典 `{a:b}`

## 函数

| 函数 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `len(对象)` | 键值对个数 | `int` | `len({'a':1,'b':2}) = 2` |
| `dict(?可迭代对象)` | 创建字典 | `dict` | `dict([('a',1)]) = {'a': 1}`<br>`dict(a=1, b=2) = {'a':1,'b':2}` |

## 方法

| 方法 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `d.get(键, ?默认值)` | 安全取值；默认值默认 `None` | 值或默认值 | `{'a':1}.get('b', 0) = 0` |
| `d.keys()` | 所有键 | 视图（可迭代） | `list({'a':1}.keys()) = ['a']` |
| `d.values()` | 所有值 | 视图（可迭代） | `list({'a':1}.values()) = [1]` |
| `d.items()` | 所有键值对 | 视图，每次给 `(键, 值)` | `for k, v in d.items(): ...` |
| `d.update(另一个字典)` | 批量更新；有则覆盖，无则新增 | `None` | `d.update({'b':2})` |
| `d.pop(键, ?默认值)` | 删除键并返回值 | 值 | `{'a':1}.pop('a') = 1`<br>没有且没给默认值 → `KeyError` |
| `d.setdefault(键, ?默认值)` | 有就取，没有就先设再取 | 值 | `d.setdefault('x', []).append(1)` |
| `d.clear()` | 清空 | `None` | `d.clear() --> {}` |
| `d.copy()` | 浅拷贝 | `dict` | `d.copy() = d` |

## 三个坑

| 坑                | 说明                                                    |
| ---------------- | ----------------------------------------------------- |
| 键必须可哈希           | `{[1,2]: 'x'}` 会 `TypeError`；元组可以当键                   |
| `d[0]` 不是“第 0 个” | 是找**键 0**；没有就 `KeyError`                              |
| 遍历时不能改大小         | `for k in d: del d[k]` 会 `RuntimeError`，要删先 `list(d)` |

# 集合 `{a,b}`

## 函数

| 函数 | 作用 | 返回 | 示例 |
|---|---|---|---|
| `len(对象)` | 元素个数 | `int` | `len({1,2}) = 2` |
| `set(?可迭代对象)` | 创建集合，自动去重 | `set` | `set([1,1,2]) = {1,2}`<br>`set()` 得到空集合 |

## 方法

| 方法                              | 作用                | 返回     | 示例                                          |
| ------------------------------- | ----------------- | ------ | ------------------------------------------- |
| `s.add(元素)`                     | 加一个元素，已存在不重复加     | `None` | `s.add(3)`                                  |
| `s.remove(元素)`                  | 删除元素；不存在报错        | `None` | `s.remove(1)`<br>不存在 → `KeyError`           |
| `s.discard(元素)`                 | 删除元素；不存在**也**不报错  | `None` | `s.discard(9)` 无变化                          |
| `s.pop()`                       | 随机删一个并返回          | 元素     | `{1,2}.pop()` 可能是 1 或 2<br>空集合 → `KeyError` |
| `s.clear()`                     | 清空                | `None` | `s.clear() --> set()`                       |
| `s.union(另一个集合)`                | 并集，返回**新集合**      | `set`  | `{1,2}.union({2,3}) = {1,2,3}`              |
| `s.intersection(另一个集合)`         | 交集，返回**新集合**      | `set`  | `{1,2}.intersection({2,3}) = {2}`           |
| `s.difference(另一个集合)`           | 差集（在 A 不在 B）      | `set`  | `{1,2}.difference({2,3}) = {1}`             |
| `s.symmetric_difference(另一个集合)` | 对称差（只在其中一个里）      | `set`  | `{1,2}.symmetric_difference({2,3}) = {1,3}` |
| `s.issubset(另一个集合)`             | 我是不是对方的子集         | `bool` | `{1,2}.issubset({1,2,3}) = True`            |
| `s.issuperset(另一个集合)`           | 我是不是对方的超集         | `bool` | `{1,2,3}.issuperset({1,2}) = True`          |
| `s.update(另一个集合)`               | 把对方元素**并入自己**（原地） | `None` | `s.update({2,3})`                           |

# 附：序列通用操作

适用于 **字符串 / 列表 / 元组**；字典和集合不支持索引和切片。

| 操作 | 说明 | 示例 |
|---|---|---|
| `s[i]` | 索引，负数从右往左 | `'abc'[0] = 'a'`；`[1,2][-1] = 2` |
| `s[a:b]` | 切片，左闭右开 | `'abcd'[1:3] = 'bc'` |
| `len(s)` | 元素个数 | `len('abc') = 3` |
| `x in s` | 成员判断 | `'b' in 'abc' = True` |
| `s + t` | 拼接 | `[1] + [2] = [1,2]` |
| `s * n` | 重复 | `[0] * 3 = [0,0,0]` |
| `s[:]` | 浅拷贝（列表常用） | `a[:]` 等价于 `a.copy()` |

> 索引越界会 `IndexError`；**切片越界不报错**，`'abc'[0:100]` 还是 `'abc'`。

# 文件读写
>假设已经创建了一个称为 f 的文件对象

| 方法               | 作用                                                         | 返回     | 示例  |
| ---------------- | ---------------------------------------------------------- | ------ | --- |
| `f.read(?读取的大小)` | 从**当前位置**读取最多指定数量的字符；省略时读取剩余全部内容。将他们合为一个字符串返回，`\n`之类的也包含在内 | `str`  |     |
| `f.readline()`   | 从当前位置开始一次读一行，返回一个字符串，**行尾的换行符 `\n` 会保留**在返回值里              | `str`  |     |
| `f.readlines()`  | 全部读完，将所有的行以字符串的形式保存在一个列表里，行尾的换行符 `\n` 会保留                  | `list` |     |
| `f.write(内容)`    | 将指定的内容写入该文件，文本格式要求是字符串，不能直接整数/列表，本身返回写入的字符数                | `int`  |     |
| `f.close()`      | 关闭文件                                                       | `None` |     |
| `next(f)`        | 返回文件下一行                                                    | `str`  |     |

## csv 模块 import csv
>假设`w=csv.writer(f)`

| 方法                     | 作用                                                         | 返回             | 示例  |
| ---------------------- | ---------------------------------------------------------- | -------------- | --- |
| `csv.reader(文件对象)`     | 创建解析记录的迭代器，每一行解析为一个列表，不负责指定读取                              | `迭代器`          |     |
| `csv.DictReader(文件对象)` | 创建按记录产出字典的迭代器，每一行按照表头列对应为字典，作为迭代器备用，会自动把第一行当表头，不要next，会丢数据 | `迭代器`          |     |
| `csv.writer(文件对象)`     | 产生一个`csv.writer`对象，大概就是产生了一个通向文件的道路，后面的写入操作都需要在他的基础上       | `csv.writer`对象 |     |
| `w.writerow(单个列表·)`    | 在文件里面写入单行列表，**并在末尾自动加上行终止符**                               | `int`          |     |
| `w.writerows(列表里面为列表)` | 写入多行数据，**并在每行末尾自动加上行终止符**                                  | `None`         |     |
