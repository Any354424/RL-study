# 1、变量与赋值
## 1.1、变量
Python的变量不需要声明类型，直接赋值就行。变量名是大小写英文、数字和`_`的组合，且不能用数字开头。也支持unicode的中文
	*这种变量本身类型不固定的语言称之为**动态语言**，与之对应的是**静态语言**。静态语言通常在定义变量时指定变量类型，如果赋值的时候类型不匹配则报错，譬如c语言。*

## 1.2、赋值
每个变量在使用前都必须赋值，变量赋值以后该变量才会被创建。
	等号`=` 用来给变量赋值。等号左边是变量名，右边是存储在变量中的值

允许同时为多个变量赋值，也可以为多个变量同时指定不同的值
例如`a = b = c = 1`和`a,b,c=1,2,3`
	当我们写`a = 'ABC'`时，计算机做了两件事
	1. 在内存中创建了一个`'ABC'`的字符串；
	2. 在内存中创建了一个名为`a`的变量，并把它指向`'ABC'`。

变量就是变量，它没有类型，我们所说的类型是变量所指的内存中对象的类型。
当我们进行变量操作时，实际上是对变量所指的对象进行操作
	所以对列表/集合进行操作时，不用`=`来试图复制一个对象，此时等号左右指的是同一个对象，`a=[];b=a;b.append(1)实际就是a.append(1)`
	而是用`.copy()`来重新在内存里面创建一个对象（浅拷贝只新建外层容器，内部对象仍可能共享）
用`==`来判断两个变量所指对象值是否相同，用`is`判断两个变量所指对象是否相同

# 2、数字与运算符
Python中有6种标准数据类型：
- `Number`（数字）
- `String`（字符串）
- `List`（列表）
- `Tuple`（元组）
- `Set`（集合）
- `Dictionary`（字典）
这一部分为数字`Number`，其他可迭代对象在数据类型一章。

## 2.1、数字
Python里可作为数字来用的有 `int`、`float`、`bool`、`complex`（复数）
其中`int`、`float`、`complex`是数字类型，`bool`为从`int`继承而来的子类，`type(True)`和`isinstance(False,int)`得到的分别是`bool`和`True`
`bool`中`True`和`False`参与算术时自动当1/0

数字对象是不允许改变的，这就意味着如果改变数字数据类型的值，赋值可让变量重新绑定到结果
在不同的机器上浮点运算的结果可能会不一样，很多十进制小数无法用二进制浮点数精确表示，不要用 `==` 比较浮点数。
## 2.2、[[Python函数方法速查表#数学|数学相关函数]]
- **内置**：`abs`（绝对值）/ `round`（四舍五入）/ `max` / `min` / `sum` / `pow`
- **类型转换**：`int()` / `float()` / `complex()` / `bool()`
- **`math` 模块**（先 `import math`）：`sqrt` / `ceil` / `floor` / `pi` / `e` / `sin` / `cos`
- **`random` 模块**：`random()` 取 [0,1) / `randint(a,b)` / `choice(序列)` / `shuffle(列表)` / `seed(n)` 固定种子
- **易混**：`//` 是向下取整（`-7 // 2` 是 `-4`）；`round(2.5)` 是 2 不是 3（银行家舍入）

# 3、布尔与比较

## 3.1、bool 类型
bool型数据只有两个值 `True` / `False`，首字母必须大写
`bool` 是 `int` 的子类：
	  `isinstance(True, int)` → `True`
	  `True + 1` → `2`，`True * 5` → `5`

单个数据判断是否真假时，常见有这 8 个是假值（还有一些空容器）：`False`、`None`、`0`、`0.0`、`""`、`[]`、`{}`、`()`（含空集合 `set()`）
为了区分假值：`if not items`,比 `len(items) == 0` 干净
## 3.2、布尔相关运算
### 比较运算符
`==` `!=` `>` `<` `>=` `<=`
- 返回的是 **`True` / `False`（bool 类型）**
- **链式比较**：`0 <= x <= 100`，等价于 `0 <= x and x <= 100`，但 x 只求值一次
- **可以跨类型比相等**：`1 == 1.0` → `True`，`1 == "1"` → `False`
- **部分类型之间可以比较大小**，例如 `1 < 1.5`，`1 < "1"` → `TypeError`
