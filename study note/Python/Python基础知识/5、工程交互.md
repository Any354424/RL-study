# 2、文件读写
在 Python 中，文件操作通过 `open()` 函数完成。该函数会返回一个文件对象（file object），用于后续的读取或写入操作。（有点复杂，可能不需要了解？）

`open()` 的基本语法如下：
	`open(filename, mode)`
- **filename**：要访问的文件路径（字符串）。
- **mode**：文件打开模式，用于指定读写方式。该参数是可选的，默认值为 `r`（只读)
单用open需要在处理完文件后加`.close()`，保证文件最终被关闭。但如果处理过程出错则文件一直关不了，所以用with来处理
`with open("文件路径", "模式代码", encoding="编码方式") as f:`
    `content = f.函数()`

## 2.1 模式

| 模式     | 文件不存在                 | 文件存在                |
| ------ | --------------------- | ------------------- |
| `"r"`  | 报 `FileNotFoundError` | 只读                  |
| `"w"`  | **创建**                | **清空**后写            |
| `"a"`  | **创建**                | 追加到末尾               |
| `"x"`  | 创建                    | 报 `FileExistsError` |
| `"r+"` | 报错                    | 读写，不清空              |
## 2.2、csv格式文件
CSV（Comma-Separated Values）文件是一种常见的文件格式，用于存储表格数据。由纯文本组成，每一行代表表格中的一行数据，而每一列则通过逗号（或其他分隔符）分隔。
	name,age
	canwe,18
	xl,20
要读取 CSV 文件，可以使用 `csv.reader` 对象。以下是一个简单的示例：


```python
import csv

with open("data.csv", "r", encoding="utf-8", newline="") as f:
    reader = csv.reader(f)
    header = next(reader, None)

    for row in reader:
        name = row[0]
        age = int(row[1])
        print(name, age)
```
这里面的`csv.reader`函数不像`file.read`那样，它返回的并不是一个字符串，是一个**逐行产出列表的迭代器**，里面的每个列表是对csv格式解析后的用`','`隔开的存储（类似`split`），每次调用 `next(reader)`，或执行一次 `for row in reader` 的迭代，就取得一条解析后的记录；默认情况下，记录里的字段都是字符串
由于`reader`是一个迭代器，可以很方便地用`r=next(reader)`跳过一行，可以用在遍历开始前去掉表头

# 3、异常、调试与测试

### 3.1 异常类型

| 异常 | 什么时候抛 | 例子 |
|---|---|---|
| `ValueError` | **类型对，值不合法** | `int("abc")`、`int("3.5")` |
| `TypeError` | **类型不匹配** | `"a" + 1`、`len(5)` |
| `KeyError` | 字典没有这个键 | `d["x"]` |
| `IndexError` | 下标越界 | `lst[10]` |
| `ZeroDivisionError` | 除数为 0 | `1 / 0` |
| `FileNotFoundError` | 文件不存在 | `open("a.txt")` |
| `AttributeError` | 对象没这个属性 | `"abc".foo()` |
| `NameError` | 变量没定义 | 用了没赋值的变量 |
| `UnicodeDecodeError` | 解码失败 | 用 gbk 读 utf-8 文件 |
| `json.JSONDecodeError` | JSON 格式坏 | `json.loads("{bad}")` |

### 3.2 try / except / else / finally

```python
try:
    x = int(input())
except ValueError:
    print("不是数字")
else:
    print("转换成功", x)
finally:
    print("无论如何都执行")
```

- `except` 可以有多个，**从上往下匹配，第一个匹配的执行**（像 `elif`）
- `else`：`try` 正常执行完毕时执行；提前 `return` 等也不会进入
- `finally`：**一定执行**，常用来清理资源

### 3.3 不要裸 except
```python
except:         # ❌ 什么都抓，连 Ctrl+C 都抓，程序退不出去
    pass
```

```python
except Exception as e:  # 次选：至少能看到错误
    print(e)
```
`Exception`是大多数常规异常的基类
```python
except ValueError:      # ✅ 优先：只抓你预料到的那一种
    ...
```
`KeyboardInterrupt`（Ctrl+C）和 `SystemExit` 继承的是 `BaseException`，不是 `Exception`，所以裸 `except:` 会把它们一起吞掉。

### 3.4 主动抛出

```python
def grade(score):
    if not 0 <= score <= 100:
        raise ValueError(f"成绩必须在 0-100，收到 {score}")
```
`raise 异常类型(错误信息)`，执行到这一行，程序立即中断当前流程，向上层抛异常，错误信息要能让人**不看代码就知道哪里错**。最好带上行号、字段名、实际值
捕获后重新抛出（保留原始信息）：

```python
except ValueError as e:
    print("记录日志")
    raise
```

### 3.7 四个坑

| 坑              | 说明                                                   |
| -------------- | ---------------------------------------------------- |
| `except: pass` | 把错误吞掉，出问题时完全不知道发生了什么                                 |
| `except` 顺序错   | `except Exception` 写在 `except ValueError` 前面，后者永远轮不到 |
| 只打印不抛出         | 捕获后应合理处理；无法处理时可重新抛出                                  |
