# 1、判断与条件
条件语句是通过一条或多条语句的执行结果（True 或者 False）来决定执行的代码块
## 1.1 if / elif / else
	if condition_1: 
		statement_block_1 
	elif condition_2: 
		statement_block_2 
	else:
		statement_block_3
- **从上往下，只执行第一个满足的分支**，后面的不再检查
- 冒号不能漏，块内缩进 4 空格
- 条件只关心真假，不要求是 `bool`：
	`if []:` 等价于 `if False:`
## 1.2 条件表达式（三元）
读法：**`A if 条件 else B`** —— 条件真取 A，假取 B。
	grade = "通过" if score >= 60 else "不通过"
- 它是**表达式**，能放在赋值、函数参数里
- 不能写语句：`x = 1 if c else y = 2` 是语法错误
### 1.3 match / case（Python 3.10+）

```python
match command:
    case "start":
        ...
    case "stop":
        ...
    case _:            # 兜底，类似 default
        ...
```

- `case _` 匹配所有剩下的情况
- 比一长串 `elif` 清晰，但不是必须用

# 循环与迭代
Python 中的循环语句有 for 和 while

| 关键字 / 函数      | 说明                      |
| ------------- | ------------------------|
| `for`         | 迭代循环，遍历序列或可迭代对象         |
| `while`       | 条件循环，条件为 True 时持续执行     |
| `break`       | 跳出**当前最内层循环**           |
| `continue`    | 跳过本次剩余代码，进入**下一次**迭代    |
| `else`（循环）    | 循环**正常结束**（没被 break）时执行 |
| `pass`        | 空语句，占位用                 |
| `range()`     | 生成整数序列                  |
| `enumerate()` | 遍历时同时拿到下标和值             |
| `zip()`       | 并行遍历多个序列                |
## 2.1 for
for 循环可以遍历任何可迭代对象，如一个列表或者一个字符串,也可以是文件
	for `<variable>`in `<sequence>`:
		`<statements>`
## 2.2 while
while可以用来实现无限循环
	while 判断条件(condition)：
	    执行语句(statements)……

# 2.3 range

```python
range(stop)                  # 0 .. stop-1
range(start, stop)           # start .. stop-1
range(start, stop, step)     # 带步长
```
- **左闭右开**：`range(5)` 是 `0,1,2,3,4`，**不含 5**
- `range` 返回惰性对象，不是列表；要看内容用 `list(range(5))`
- 可重复遍历，不预先存储全部整数
- 负步长可以倒数：`range(5, 0, -2)` → `5, 3, 1`
### 2.4 enumerate 与 zip

```python
for i, x in enumerate(lst):          # 下标从 0 开始
    ...
for i, x in enumerate(lst, 1):       # 计数从 1 开始
    ...
for a, b in zip(names, ages):        # 按下标配对
    ...
```
- `enumerate`：需要下标时用它
- `zip`：以**最短**的为准，长的部分多余停止配对
- 两者返回的都是**一次性迭代器**，遍历完就空了

### 2.5 break / continue / else

- `break`：跳出**当前最内层循环**
- `continue`：只跳过本次剩下的语句
- `else`：**循环正常跑完才执行**，`break`、异常、`return` 提前离开时不执行”

`while` 也有 `else`，规则一样。
### 2.6 pass

```python
for x in items:
    pass          # 先占位，以后再写
```

什么都不做，只为保持语法完整。
### 2.7 四个坑

| 坑                 | 说明                                            |
| ----------------- | --------------------------------------------- |
| 遍历时删元素            | 删除会移动后续元素，可能导致漏处理；要删用 `for x in lst[:]` 或重建列表 |
| 忘改循环条件            | `while i < 10:` 里没有 `i += 1` → 死循环            |
| `range(5)` 当成 1~5 | 实际是 0~4                                       |
| 以为循环变量会消失         | Python 没有块作用域，循环结束后 `i` **仍然存在**（和 C 不同）      |
# 3、迭代器与生成器
## 迭代器
迭代是访问集合元素的一种方式。
迭代器是一个可以记住遍历的位置的对象。对象从集合的第一个元素开始访问，直到所有的元素被访问完结束。迭代器只能往前不会后退。耗尽后不能直接重新遍历，但不会清空原列表
迭代器有两个基本的内置函数：`iter()`和 `next()
`iter()`用于创建迭代器
	`values=[1,2,3,4]`
		`it = iter(values)`
`next()`用于迭代一次
## 生成器
使用了 **yield** 的函数被称为生成器
含 `yield` 的普通函数称为生成器函数，调用后得到生成器对象。  
`next()` 或 `for` 推进生成器；遇到 `yield` 时产出值并暂停，下次从暂停处继续。  
`return` 或执行到末尾会结束生成器，不会撤销已发生的对象修改。
跟普通函数不同的是，生成器是一个返回迭代器的函数，只能用于迭代操作，更简单点理解生成器就是一个迭代器
