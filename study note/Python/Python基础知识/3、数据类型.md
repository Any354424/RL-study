# 切片索引
字符串、列表、元组支持位置索引和切片。索引越界报错；切片边界超出范围会自动截取有效部分；字典按键查找；集合无序，不支持下标
	`[]`通过索引获取对象中元素
	`[ : ]`截取对象中的一部分，遵循**左闭右开**原则
	`[起点:终点:步长]`步长取负为反向读取，不可写0
切片**左闭右开**，索引越界报错，切片越界不报错
	`[a:b]` 包含 a，不包含 b

## 1.3、格式化
字符串格式化就是“把变量或表达式的值嵌进一段文本里”，让字符串从固定文字变成可动态拼接的模板
	一种是使用%，`'%s'%(变量)`，在字符串里面用`%+字母`的形式代替要导入的变量，在字符串后面用`%(变量)`把对应的变量按顺序写进去
		`%s` 格式化字符串变量  `%d`格式化整数变量  `%f`格式化浮点数变量
	一种是使用f-string，`f'{变量}'`也就是在字符串前面加一个`f`，然后在字符串里面用{变量}的形式把所需的变量写在花括号里面
		`{变量:.1f}`，保留一位小数 `{变量:.0f}`,四舍五入到整数
		`{变量:.1%}`，保留一位小数,自动乘 100 并加 %

- **查找**：`in`（只问在不在）/ `find`（找不到返回 -1）/ `index`（找不到报错）/ `count`

# 2、列表
列表是最常用的 Python 数据类型，有序、可变、可重复，元素类型不限。用方括号创建：`[1, "a", True]`
这些特征决定了它可以使用下标和切片，但不哈希，不能作为字典的键，不能放进集合
## [[Python函数方法速查表#列表 `[a,b,c]`|列表相关函数]]
- **增**：`append`（加一个对象，整个塞进去）/ `extend`（拆开逐个加）/ `insert`
- **删**：`remove`（按值删，找不到报错）/ `pop`（按下标删，返回被删的）/ `del`（语句，不返回值）
- **改查**：`lst[i] = x`、`index`、`count`、`in`
- **排序**：`sort`（原地，返回 `None`）/ `sorted`（返回新列表）
# 3、元组
元组是不可变的有序序列，与列表较为相似，主要区别在于不可变。元组所有元素都可哈希时，元组才可哈希
	本身元素不能改，但是元素指向的内容可以改
**单元素元组必须带逗号**
	`a = (1)`是整数 1，`b = (1,)`才是元组，`c = ()`为空元组

**解包**：`a, b = (1, 2)`；交换 `a, b = b, a`；函数“返回多个值”其实就是返回元组
##  [[Python函数方法速查表#元组 `(a,b,c)`|元组相关函数]]
- 只有 `count` / `index`，参数和返回值与列表完全一样
- 列表的修改方法（`append` / `insert` / `remove` / `pop` / `clear` / `sort` / `reverse`）**元组都没有**
- 能用的还有索引、切片、`in`、`+`、`*`、`len`

# 4、字典
键值映射，键必须**可哈希且唯一**
## [[Python函数方法速查表#字典 `{a: b}`|字典相关函数]]
- **取值**：`d[键]`（没有就 `KeyError`）/ `d.get(键, 默认)`（不报错）
- **遍历**：`for k in d` 遍历键 / `.values()` 遍历值 / `.items()` 同时拿键值
- **增改**：`d[键] = 值` / `d.update(另一个字典)`
- **删除**：`d.pop(键)` / `del d[键]`
- **易混**：`d[0]` 是找**键 0**，不是第 0 个；键必须可哈希，列表不行、元组可以
# 5、集合 
无序、不重复。
## [[Python函数方法速查表#集合 `{a,b}`|集合相关函数]]
- **增删**：`add` / `remove`（不存在报错）/ `discard`（不存在不报错）/ `pop`（删除并返回一个元素，不保证选中哪个）
- **运算**：`union` / `intersection` / `difference` / `symmetric_difference`
- **判断**：`issubset` / `issuperset`
- **运算符**：`&` 交、`|` 并、`-` 差、`^` 对称差
- **易混**：空集合是 `set()` 不是 `{}`；`pop()` 是随机的；不能索引和切片

# 6、推导式
推导式是一种独特的数据处理方式，可以从一个数据序列构建另一个新的数据序列的结构体，适用于生成列表、字典、集合和生成器（元组需要进行`tuple()`处理）。
大体的格式是：
	所需的变量：不是必须的处理函数 for i in 另一个迭代对象 if条件（如果是else要写for前面）
	`[i for i in range(30) if i % 3 == 0]`
	
 筛选：只保留满足条件的元素
`[x for x in range(6) if x % 2 == 0]`
 条件表达式：每个元素都生成一个结果
`['偶数' if x % 2 == 0 else '奇数' for x in range(6)]`
在外面加上对应的`[{()}]`
字典的话格式为
	{ key_expr: value_expr for value in collection }
