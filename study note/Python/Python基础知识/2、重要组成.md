# 1、函数
函数是组织好的，可重复使用的，用来实现单一，或相关联功能的代码段
### 1.1 定义与调用

```python
def add(a, b):
    """返回两数之和"""
    return a + b

add(1, 2)        # 3
add(b=2, a=1)    # 3，关键字传参，顺序无关
```

- 没有 `return` 的函数返回 `None`
- `return a, b` → 实际返回**元组** `(a, b)`
- 接收时可以直接解包：`x, y = f()`
- `return` 之后的代码不执行
- 函数名后面不加括号，拿到的是**函数对象本身**，不是调用结果
## 1.2 四种参数

| 类型    | 写法                       | 说明                                    |
| ----- | ------------------------ | ------------------------------------- |
| 位置参数  | `def f(a, b)`            | 按顺序传                                  |
| 关键字参数 | `f(b=2, a=1)`            | 按名字传，顺序无关，但是要写`关键词=...`               |
| 默认参数  | `def f(a, b=2)`          | 不传就用默认值；**普通位置参数中，必填参数不能放在带默认值的参数后面** |
| 可变参数  | `def f(*args, **kwargs)` | 收集多余参数，`*`以元组形式传入，`**`以字典形式传入         |

## 1.3 作用域

```python
x = 10

def f():
    x = 20        # 这是新的局部变量，不影响外面的 x
    return x
```

- 函数内部**能读**全局变量，但**赋值会创建局部变量**
- 要在函数内**重新绑定全局变量名**时需要 `global`，**尽量别用**——用参数传入、用返回值传出才是正道
## 1.4 四个坑

| 坑         | 说明                                                        |
| --------- | --------------------------------------------------------- |
| 可变默认参数    | `def f(lst=[])` 的 `[]` **只创建一次**，所有调用共享；要用 `lst=None` 再判断 |
| 覆盖内置名     | `def list(...)`、`sum = 0` 之后，内置函数就用不了了                    |
| 偷偷修改传入的列表 | 函数里 `lst.append()` 会改到调用方的对象                              |
| 默认参数顺序    | `def f(a=1, b)` 是语法错误，有默认值的必须放后面                          |

# 2、lambda

lambda 函数是一种小型、匿名的、内联函数，它可以具有任意数量的参数，但只能有一个表达式
```python
f = lambda x: x + 1
```
等价于：
```python
def f(x):
    return x + 1
```

**lambda 函数特点：**
- lambda 函数是匿名的，它们没有函数名称，只能通过赋值给变量或作为参数传递给其他函数来使用。
- lambda 函数通常只包含一行代码，这使得它们适用于编写简单的函数

# 3、类与实例
- **类(Class):** 用来描述具有相同的属性和方法的对象的集合。它定义了该集合中每个对象所共有的属性和方法。对象是类的实例。
	`class man:`
		属性
		方法
- **对象（实例）**：通过类创建出来的具体个体。实例拥有自己的**实例变量**，并可通过类访问**类变量**和**方法**。类变量属于类本身，被所有实例共享
- **实例化**：创建一个类的实例，类的具体对象。
	`a=man()`
- **方法**：类中定义的函数。
	 类的方法与普通的函数只有一个特别的区别——它们必须有一个额外的**第一个参数名称**, 按照惯例它的名称是 self，用于表示类的实例（对象）自身。它是一个指向实例的引用，使得类的方法能够访问和操作实例的属性。
	`class man:`
		`def say(self):`
			`print('what can')`
- **类变量**：类变量在整个实例化的对象中是公用的。类变量定义在类中且在函数体之外。类变量通常不作为实例变量使用。
	`class man:`
		`gender='man'`
		`def __init__(self):`
			`pass`
- **数据成员**：类变量或者实例变量用于处理类及其实例对象的相关的数据。
- **方法重写**：如果从父类继承的方法不能满足子类的需求，可以对其进行改写，这个过程叫方法的覆盖（override），也称为方法的重写。
	`class man:`
		`def say(self):`
			`print('what can')`
	`class manba(man):`
		`def say(self):`
			`print('what can i say')`
- **局部变量**：方法中的局部变量属于该方法调用的局部作用域；`name` 是局部变量，`self.name` 是实例属性。
- **实例变量**：在类的声明中，属性是用变量来表示的，这种变量就称为实例变量，实例变量就是一个用 self 修饰的变量。
	`class man:`
		`gender='man'`
			`def __init__(self):`
				`self.name='ks'`
- **继承**：即一个派生类（derived class）继承基类（base class）的字段和方法。继承也允许把一个派生类的对象作为一个基类对象对待。
	`class man:`
		`def __init__(self,name):`
			`self.name=name`
	`class manba(man):`
		`def __init__(self,name,age):`
			 `super().__init__(name)`
			 `self.age=age`

## 3.1 特殊方法（钩子）

实现某个方法，对应的语法就能用：

| 方法         | 什么时候自动调用                    |
| ---------- | --------------------------- |
| `__init__` | 初始化已经创建的实例                  |
| `__str__`  | `print(obj)`、f-string       |
| `__repr__` | 调试显示、打印列表                   |
| `__len__`  | `len(obj)`                  |
| `__eq__`   | `obj1 == obj2`              |
| `__lt__`   | `obj1 < obj2`（可用于 `sorted`） |
| `__add__`  | `obj1 + obj2`               |

## 3.2 私有
### 类的私有属性

**__private_attrs**：两个下划线开头，声明该属性为私有，不能在类的外部被用原名字使用或直接访问。在类内部的方法中使用时 **self.__private_attrs**。
### 类的私有方法

**__private_method**：两个下划线开头，声明该方法为私有方法，只能在类的内部调用 ，不能在类的外部用原名字调用。**self.__private_methods**

**名字会被改写成 `_类名__名字`，用来避免子类意外覆盖，不是严格的访问控制**
## 3.3 坑

| 坑              | 说明                                            |
| -------------- | --------------------------------------------- |
| 可变类属性          | 所有实例共用                                        |
| `__add__` 返回元组 | `return (x, y)` 会让链式相加崩掉，要返回 `Vec2(...)`      |
| `__eq__` 不判类型  | `a == 5` 会 `AttributeError`，先 `isinstance` 再比 |

# 4、模块与包
## 4.1 模块 = 一个 `.py` 文件

文件名去掉 `.py` 就是模块名。`utils.py` 就是模块 `utils`。
`import` 做三件事：找到文件 → 执行它的顶层代码 → 把名字交给你用。
通常首次导入时执行，后续导入复用缓存中的模块
## 4.2 四种 import 写法

```python
import math
math.sqrt(16)

from math import sqrt
sqrt(16)

import numpy as np
np.array([1, 2])

from math import sqrt as sq
sq(16)
```
**不推荐** `from math import *`
## 4.3 `if __name__ == "__main__":`

```python
def add(a, b):
    return a + b

if __name__ == "__main__":
    print(add(1, 2))
```

- **直接运行**这个文件时，`__name__` 是 `"__main__"`，块内代码执行
- **被 import** 时，`__name__` 是模块名，块内代码**不执行**

作用：让同一个文件既能当脚本跑，又能被别人当模块用，而不会在 import 时执行测试代码。
## 4.4 import 去哪里找

按 `sys.path` 顺序：

1. **脚本所在目录**（不是当前工作目录！）
2. `PYTHONPATH` 环境变量
3. 标准库目录
4. `site-packages`（pip 装的第三方库）

> ⚠️ **`import` 找的是“脚本所在目录”，`open()` 找的是“当前工作目录（CWD）”**——这两个经常不是一处。排查先 `print(os.getcwd())` 和 `print(sys.path[0])`
>

| ------------- | ---------------------------------- |

| `re`          | 正则                                 |

## 4.7 四个坑

| 坑       | 说明                                                              |
| ------- | --------------------------------------------------------------- |
| 文件名撞标准库 | 项目里叫 `random.py`，`import random` 会导入你自己的文件                      |
| 循环导入    | `a` 导 `b`，`b` 又导 `a` → `ImportError`循环导入可能因模块尚未初始化完成而失败，不是必然失败。 |
| 改完模块不生效 | 解释器有缓存，可能需要重启                                                   |
| 路径搞混    | 见 4.4，脚本目录 ≠ 当前工作目录                                             |
