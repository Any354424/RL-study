# 值迭代
贝尔曼最优公式$$
v=f(v) := \max_\pi (r_\pi + \gamma P_\pi v)
$$我们知道可以用迭代算法来求出$$
v_{k+1} = f(v_k) = \max_\pi (r_\pi + \gamma P_\pi v_k)
$$这个方法叫做值迭代 
步骤是这样的，已知$r_\pi,\gamma$：
- 我们先给一个v0，这个可以是任何值，影响的只是迭代速度
- 将v0带入$\pi_{k+1} = \arg\max_\pi (r_\pi + \gamma P_\pi v_k)$里面的vk，求出更好的$\pi_{k+1}$
- 知道了$\pi_{k+1}$，带入迭代算法$v_{k+1} = \max_\pi (r_\pi + \gamma P_\pi v_k)$
- 将$v_{k+1}$带入第二步，迭代Policy（policy update）
- 将迭代的Policy带入第三步，求出更进一步的v（value update）

可以看到，值迭代的核心主要是两步，也就是policy update和value update
## policy update
$$\pi_{k+1} = \arg\max_\pi (r_\pi + \gamma P_\pi v_k)$$我们可以写出他的详细形式
$\pi_{k+1}(s) = \arg{\max_\pi} \sum_{a} \pi(a|s) \left( \sum_{r} p(r|s, a)r + \gamma \sum_{s'} p(s'|s, a)v_k(s') \right), \quad \forall s \in \mathcal{S}$
这里面括号里面的所有都是已知的，所有我们就求出来了$a_k^*(s)$
根据贪心策略,将所有的概率落到最大行动价值上面，就得到了$$
\pi_{k+1}(a|s) = 
\begin{cases} 
1 & a = a_k^*(s) \\ 
0 & a \neq a_k^*(s) 
\end{cases}
$$
## value update
$$v_{k+1} = r_{\pi_{k+1}} + \gamma P_{\pi_{k+1}} v_k$$
把得到的$\pi_{k+1}$带入，可以得到最大化的vk+1

## 总结
$v_k(s) \rightarrow q_k(s, a) \rightarrow \text{\textbf{greedy policy }} \pi_{k+1}(a|s) \rightarrow \text{\textbf{new value }} v_{k+1} = \max_a q_k(s, a)$
大致如下：
当$v_k-v_{k-1}$的值大于要求的值的时候，对于第*k*th回合
	对于每一个state：
		对于每一个action：
			计算它的action value
		求出最大的action value $a_k^*(s)$
		进行策略update，把所有的概率落到这个action上面
		进行值的update

# 策略迭代
与值迭代类似，我们先给定一个用来迭代的初始值$\pi_0$
先使用$$
v_{\pi_k} = r_{\pi_k} + \gamma P_{\pi_k} v_{\pi_k}
$$这里面的$P_{\pi_k}$是去往下一个v的概率，在知道了$\pi$之后也得到了，这样通过==贝尔曼公式迭代==，不断带入$v_{\pi_k}$的值（这是一个矩阵表达式，v是一个向量，包含了所有的state value），能得到所有的state value，也就得到了$v_{\pi_k}$，也就是一个给定state，告诉state value的函数

然后$$
\pi_{k+1} = \arg \max_{\pi} (r_\pi + \gamma P_\pi v_{\pi_k})
$$可以对策略进一步（知道这个k+1一定大于k就好了，以及最后一定会收敛）
和值迭代的policy update是一样的

## 总结
当策略不满足要求时，在第*k*步
	策略更新
		先给一个最初始的$v_{\pi_k}^{(0)}$
			如果$v_{\pi_k}^{(j)}$还没有收敛的话(也就是$v_k-v_{k-1}$没满足要求)
				对每一个s
					带入贝尔曼迭代公式$v_{\pi_k}^{(j+1)}(s) = \sum_a \pi_k(a|s) \left[ \sum_r p(r|s,a)r + \gamma \sum_{s'} p(s'|s,a)v_{\pi_k}^{(j)}(s') \right]$求下一步的值，看看收不收敛
	策略迭代
		对于每一个s
			对于每一个action
				$q_{\pi_k}(s,a) = \sum_r p(r|s,a)r + \gamma \sum_{s'} p(s'|s,a)v_{\pi_k}(s')$求出它的行动价值
				然后把策略概率全落在最大的上面

# 截断策略迭代算法
复习以下概念
以下的v指的是每一个state的return的平均期望（state value）的向量（一维数组）
p指的是每一个state采取action的概率的矩阵（每行为一个加起来为一，每个行为的列表）
贪心算法：当我们知道策略（每一个state做什么动作），状态转移概率（每状态下，每一个动作的后果），奖励概率（在指定的状态，进行指定的动作，可能获得奖励的概率）后，我们可以计算每个状态的动作价值（采取所有动作的奖励（该行动的奖励和下一个state的state value）的期望），为每一个状态找到最大的行动价值，标定该行动的概率为1，迭代完，确定的策略就是最佳策略


值迭代
- 先选择一个state value的集合v
- 然后用这个集合v通过求总和最大值找到最佳策略p， 
- 用最佳的p算新的v
策略迭代
- 先选一个策略p
- 用贝尔曼公式求解出这个策略对应的价值v（可以迭代，可以逆矩阵）
- 然后用这个精确的价值v来通过求最大值来更新策略p
- 用更新了的p算新的v

我们发现其实都很接近

值迭代的本质其实就是贝尔曼最优公式的迭代，已经有了一个不准确/随便给的初始v，里面包含了一些随便的state value
通过$v_{k+1} = \max_\pi (r_\pi + \gamma P_\pi v_{k})$对这一次的$v_k$，对每一个state进行一次明确的action（贪心），更新它的state value，但不直接覆盖，而是另起副本，等填满之后用这个新的v进行代入迭代
他不在乎这个action的集合（policy）是什么，他只在乎最后的结果v是不是最大的，也就每个state的state value是不是最大的

策略迭代则是迭代里面嵌套一个迭代
第一个迭代是用一个不动的策略不断算，相当于求出来普通贝尔曼公式的迭代$v_{k+1} = r_\pi + \gamma P_\pi v_k$，这个结果是当前策略下的不动点，也就是当前策略下能得到的每个state的期望回报，也就是一个完整收敛精确的state value集合

然后用这个精确的state value集合v，去求对应的最好动作，也就是奖励与下一个state的state value之和取最大，把这些动作连起来
	要注意，state value包含的信息是所有动作的加权平均，可以认为是对旧action概率（旧策略）的一个加权平均，我选择的动作是按照这个旧策略的信息，去找当前能看到的最短视的路，从s1到s2走完之后，上一步脚下的s1的state value发生了改变，因为此时我的动作不是一个概率，是一个明确的值（如果action价值最大值不是多个），但这个不影响我的判断，因为这个改变的state value是要在完整的path走完，形成一个policy之后再次计算的。不会出现走回头路的情况，哪怕出现了，不管这个state换了什么action，还是采取旧state value，误差在下一次计算的时候再修改
修改完了action的集合policy，再代回去求新的state value集合v

所以值迭代的区别是，他一开始获得的是一个state value的集合，虽然有可能从里面推出明确的策略，但是没有那个必要，不同于策略迭代，有明确的策略可以算出精确的v，值迭代一开始就得到了一个v，所以少了一步迭代，由于开始的策略没有，所以他只是在当前的基础上，新建一个空数组，把每个state value计算贪心能得到的最大值，也就是单个action和下一个state value，和策略迭代一样先不在原数组里面改，而是填入空数组，如此这般获得一个新的v，然后就这样有点糊里糊涂的迭代下去，如果能收敛的话，那就成了

我们发现，两者都存在一个对v的迭代，一个是值迭代本身，一个是求精确v的迭代。一个每次只有一步，一个理论上要无穷次，我们可以在中间去取一个值，到了这个值，就不再迭代
